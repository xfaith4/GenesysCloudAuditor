# Genesys Best Practices Starter Pack v0.2.0

This package is a v0.2 upgrade of the initial starter set.

## Included files

- `BestPractices.md` — readable best-practices guide
- `Roadmap.md` — explicit next-step roadmap for operational maturity
- `README.md` — package overview
- `best-practices.catalog.json` — machine-readable rule catalog
- `best-practices.schema.json` — strict schema for the catalog
- `best-practices-map.json` — finding-to-best-practice mapping starter
- `best-practices-map.schema.json` — schema for the map
- `glossary.json` — starter glossary layer
- `Glossary.md` — human-readable glossary

## What changed in v0.2

The package now includes the operational layers that were missing from the first pass:

- source traceability fields
- detection strategy fields
- remediation content
- evidence examples
- ownership/accountability
- false-positive and exception handling
- control family / pillar / report grouping
- stricter JSON schemas
- separate glossary layer
- lifecycle metadata such as status and introduced version

## Notes

This remains a starter pack. It is intentionally opinionated and designed to be expanded alongside your analyzer result model and reporting layer.
