## Terms

### Queue
**Domain:** Queue

An ACD object that holds and routes interactions to eligible agents.

### Routing Method
**Domain:** Queue

The queue behavior that determines how interactions are evaluated and assigned.

### Skill Rating
**Domain:** Queue

A proficiency value assigned to an agent skill for skill-based routing.

### Wrap-Up Code
**Domain:** Queue

A disposition value used by agents to describe interaction outcome or purpose.

### Edge
**Domain:** EdgeSite

A premises-based telephony component used for local media and connectivity in BYOC Premises designs.

### Schedule Group
**Domain:** Architect

A collection of schedules, typically with timezone context, used to drive routing behavior such as open, closed, or holiday logic.

### Division
**Domain:** Security

A Genesys Cloud scoping boundary used to control access and object visibility.

### OAuth Scope
**Domain:** API

A permission grant requested by an OAuth client to access specific Genesys Cloud capabilities.

### CX as Code
**Domain:** DevOps

A declarative approach to managing supported Genesys Cloud configuration as source-controlled artifacts.

### N+1 Redundancy
**Domain:** EdgeSite

A design where the environment can sustain expected load even after one active capacity unit fails.
